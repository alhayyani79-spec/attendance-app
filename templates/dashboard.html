ℹ️ Information
How to use this system:

📌 For Family Members:
• Click Join to register for an activity
• Click Cancel if you cannot attend anymore
• Your name will appear in the attendees list for that activity

🔧 For Admin:
• Click Attendees dropdown to see who joined
• Click Remove to take someone out of an activity
• Use the Admin Control Panel to manage users and activities
• Use Backup Panel to save/restore all data to GitHub

💾 Data Safety:
• All data is automatically backed up to GitHub when changes are made
• You can manually backup or restore using the buttons above
• Your family's attendance records are safe even after server restarts
